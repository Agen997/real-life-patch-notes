One funny patch note for a bug in human biology, in the terse register of a real release note:

> v2.4.1: fixed a bug where the brain stored every song lyric from 2007 but forgot why you walked into this room.

`main.py` (Python 3.13, standard library only) writes the line, alone, to `/output/entry.txt`.

Run it: `python3 main.py`
